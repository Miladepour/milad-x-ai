## 1. Recommended website and SEO structure

### Use two separate language pages

Do not place the full Persian and English versions side by side on one URL. Publish each language on its own page:

- Persian: `https://mxaiacademy.com/fa/private-ai-courses/`
- English: `https://mxaiacademy.com/en/private-ai-courses/`

Each page should:

- Contain only one primary language in its navigation and main content
- Have its own title tag and meta description in the same language as the page
- Use one clear and visually dominant H1
- Link visibly to the other language version
- Use a self-referencing canonical tag
- Include reciprocal `hreflang` tags
- Be indexable and included in the XML sitemap
- Avoid automatic language redirection based on IP address

Recommended language tags:

```html
<link rel="alternate" hreflang="fa" href="https://mxaiacademy.com/fa/private-ai-courses/">
<link rel="alternate" hreflang="en" href="https://mxaiacademy.com/en/private-ai-courses/">
<link rel="alternate" hreflang="x-default" href="https://mxaiacademy.com/fa/private-ai-courses/">
```

Persian page root:

```html
<html lang="fa" dir="rtl">
```

English page root:

```html
<html lang="en" dir="ltr">
```

## چرا دوره خصوصی هوش مصنوعی؟

دوره‌های عمومی می‌توانند برای آشنایی اولیه مفید باشند، اما ممکن است بخشی از مطالب برای شما تکراری، بیش از حد ساده یا نامرتبط با نیاز واقعی‌تان باشد. در آموزش خصوصی، مسیر یادگیری از روی هدف، سطح دانش، نوع فعالیت و پروژه شما ساخته می‌شود.

### فقط آنچه واقعاً نیاز دارید

به جای صرف زمان برای موضوعات غیرضروری، روی مهارت‌ها، ابزارها و کاربردهایی کار می‌کنید که مستقیماً به هدف شما مرتبط هستند.

### یادگیری با پروژه واقعی

تمرین‌ها و مثال‌ها تا حد امکان بر اساس کار، کسب و کار، محتوا، وب‌سایت، محصول یا ایده واقعی شما انتخاب می‌شوند.

### سرعت متناسب با شما

اگر موضوعی را از قبل می‌دانید، سریع‌تر از آن عبور می‌کنیم. اگر بخشی نیاز به توضیح و تمرین بیشتری داشته باشد، زمان بیشتری به آن اختصاص می‌دهیم.

### بازخورد مستقیم و دقیق

در طول جلسه می‌توانید سؤال بپرسید، کار خود را اجرا کنید، اشتباهات را همان لحظه بررسی کنید و بازخورد مشخص دریافت کنید.

### تمرکز بر نتیجه قابل استفاده

هدف فقط شناخت ابزارهای هوش مصنوعی نیست. هدف این است که بتوانید پس از دوره، آموخته‌های خود را به صورت مستقل در کار یا پروژه واقعی اجرا کنید.

## 8. Conversion and layout recommendations

### Improve the current section shown in the screenshots

Replace the current four-stage process with three larger cards:

1. رزرو جلسه مشاوره
2. طراحی و ارسال برنامه آموزشی
3. تأیید برنامه و شروع جلسات

Give each stage enough width for the complete explanation. On desktop, use three equal cards or one vertical timeline. On mobile, use one card per row. Do not place the full process in a narrow right-hand column beside another long list.

### Recommended visual hierarchy

- Keep the hero full width
- Place the main CTA above the fold
- Show the consultation price immediately below the CTA
- Use six course cards in a two or three-column desktop grid
- Add anchor links from each course card to its detailed description
- Use a three-step horizontal process on large screens
- Stack the process vertically on mobile
- Use an accordion for FAQs
- Repeat the consultation CTA after the course list, process and FAQ
- Use the existing black, white and dark orange brand palette
- Use Vazir or Vazirmatn for Persian copy
- Check line height carefully because the page contains detailed Persian text
- Keep Persian content right aligned and English content left aligned
- Use descriptive icons, but never use icons as a replacement for text

- Current AI experience

  https://developers.google.com/search/docs/appearance/title-link

  https://developers.google.com/search/docs/appearance/snippet

  https://developers.google.com/search/docs/appearance/structured-data/course
